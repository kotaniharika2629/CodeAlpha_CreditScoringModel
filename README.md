Credit Scoring Model
CodeAlpha Machine Learning Internship — Task 1

Project Overview:
This project predicts good or bad credit risk using historical financial data and machine learning classification algorithms.

Dataset:
Statlog German Credit Dataset — 1,000 records and 20 features.

Algorithms:
Logistic Regression, Decision Tree, Random Forest.

Model Performance:
Model                	Accuracy	    ROC-AUC
Logistic Regression	     78%	       0.8040
Decision Tree	           63%	       0.5548
Random Forest	           74%	       0.7793

Best Performing Model:
Logistic Regression achieved the highest accuracy of 78%.
